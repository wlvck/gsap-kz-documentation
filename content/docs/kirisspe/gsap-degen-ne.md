# GSAP деген не?

**GSAP (GreenSock Animation Platform)** — бұл веб-әзірлеушілерге қуатты, жоғары өнімді анимациялар жасауға мүмкіндік беретін JavaScript кітапханасы.

## Неге GSAP?

GSAP — бұл веб-анимациялар үшін индустрия стандарты. Оны Netflix, Google, Apple, Microsoft және басқа да ірі компаниялар қолданады.

### Негізгі артықшылықтары:

- **Жоғары өнімділік** — CSS анимацияларынан тезірек жұмыс істейді
- **Кроссбраузерлік** — барлық браузерлерде бірдей жұмыс істейді
- **Қарапайым синтаксис** — үйрену оңай, қолдану ыңғайлы
- **Икемділік** — кез келген CSS қасиетін, SVG элементін, Canvas объектісін анимациялай аласыз

## Қарапайым мысал

```javascript
// Элементті 2 секундта оңға жылжыту
gsap.to(".box", {
  x: 200,
  duration: 2,
});
```

Бұл код `.box` класы бар элементті x осі бойынша 200 пиксельге жылжытады.

## Нені анимациялауға болады?

GSAP көмегімен сіз мыналарды анимациялай аласыз:

- **CSS қасиеттері** — түс, өлшем, орын, көлеңке және т.б.
- **Transform қасиеттері** — айналдыру, масштабтау, жылжыту
- **SVG атрибуттары** — path, stroke, fill және т.б.
- **Canvas элементтері** — 2D және 3D графика
- **Кез келген JavaScript объектісі** — сандық мәндерді өзгерту

## Келесі қадам

Енді GSAP-ты жобаңызға [орнатуды](/docs/kirisspe/ornatu) үйренейік.
